Wintap Data Schema:
1. Wintap_Process: Central table.  The Wintap datamodel is Process centric.  Wintap_Process contains data about process events (e.g., start, stop).
2. Wintap_CpuTrigger: contains data related to CPU usage or triggers.
3. Wintap_File: contains data about file operations (e.g., reads, writes).
4. Wintap_FocusChange: contains data about focus changes between applications.
5. Wintap_Memory: contains data about memory usage or events.
6. Wintap_APICalls: contains data about API calls made by processes.
7. Wintap_Registry: contains data about registry operations.
8. Wintap_Tcp: contains data about TCP connections.
9. Wintap_WMI: contains data about WMI (Windows Management Instrumentation) events.

The Wintap_Process table has the following schema:
1. ParentPidHash (VARCHAR): Unique identifier for the parent process. 
2. ParentPid (INTEGER): Process ID of the parent process.
3. PID (INTEGER): Process ID of the current process.
4. PidHash (VARCHAR): Unique identifier for the current process. Primary key for doing data joins.
5. AgentId (VARCHAR): Identifier for the agent collecting the telemetry.
6. ProcessName (VARCHAR): Name of the process.
7. ProcessPath (VARCHAR): Path to the process executable.
8. StartTime (BIGINT): Time when the process started (in Unix Epoch UTC format).
9. FileMd5 (VARCHAR): MD5 hash of the process executable file.
10. FileSha2 (VARCHAR): SHA-2 hash of the process executable file.
11. UserName (VARCHAR): User associated with the process.
12. ProcessArgs (VARCHAR): Arguments passed to the process at startup.
13. EventTime (BIGINT): Time of the event (in Unix Epoch UTC format).
14. MessageType (VARCHAR): Event category (e.g., PROCESS).
15. ActivityType (VARCHAR): Specific action within the category (e.g., Start, Stop, Refresh). Refresh indicates that Wintap did not receive the native start event but detected it during a scheduled poll for existing processes.
16. CommandLine (VARCHAR): Full command line used to start the process.
17. Hostname (VARCHAR): Hostname of the machine where the process is running.
18. UniqueProcessKey (VARCHAR): The Event Tracing For Windows (ETW) unique identifier for the process.
19. ReceiveTime (BIGINT): Time when the telemetry was received.

### Wintap_File:  This is an aggregated event type where events are summarized by the Wintap agent on a 10 second interval
1. ActivityType (VARCHAR): Specific file operation (e.g., Read, Write).
2. ProcessName (VARCHAR): Name of the process performing the file operation.
3. AgentId (VARCHAR): Identifier for the telemetry agent.
4. BytesRequested (INTEGER): The sum of bytes requested for all File events within the 10 second aggregation interval.
5. EventCount (INTEGER): Count of file events occurring within the 10 second aggregation interval.
6. FirstSeen (BIGINT): Timestamp of the first file event occurring within the 10 second aggregation interval.
7. LastSeen (BIGINT): Timestamp of the last file event occurring within the 10 second aggregation interval. 

8. PidHash (VARCHAR): Unique identifier for the process.
9. PID (INTEGER): Process ID.
10. Hostname (VARCHAR): Hostname of the machine.
11. File_Path (VARCHAR): Path to the file involved in the operation.
12. File_Hash (VARCHAR): Hash of the file.
13. MessageType (VARCHAR): Event category (e.g., FILE).
14. EventTime (BIGINT): Time of the event 

### Wintap_Tcp:  This is an aggregated event type where events are summarized by the Wintap agent on a 10 second interval
1. ConnId (VARCHAR): Unique identifier for the TCP connection.
2. PidHash (VARCHAR): Unique identifier for the process.
3. MinPacketSize (BIGINT): Minimum packet size observed within the 10 second aggregation.
4. MaxPacketSize (BIGINT): Maximum packet size observed within the 10 second aggregation.
5. PacketSizeSquared (BIGINT): Squared packet size (likely for statistical analysis).
6. LocalIpAddr (BIGINT): Local IP address as a LONG data type.
7. LocalIpPrivateGateway (VARCHAR): Local private gateway IP.
8. LocalPort (INTEGER): Local port number.
9. RemoteIpAddr (BIGINT): Remote IP address as a LONG data type.
10. RemoteIpPrivateGateway (VARCHAR): Remote private gateway IP.
11. RemotePort (INTEGER): Remote port number.
12. Protocol (VARCHAR): Protocol used (e.g., TCP, UDP).
13. InitialSeq (INTEGER): Initial sequence number.
14. IpEvent (VARCHAR): Type of IP event.
15. PacketSize (INTEGER): Size of the packet.  This is a sum of all packets within the 10 second aggregation interval.
16. IncrType (VARCHAR): Increment type (likely for sequence analysis).
17. EventCount (INTEGER): Count of TCP events.
18. FirstSeenMs (BIGINT): Timestamp of the first TCP event occurring within the 10 second aggregation interval. 
19. LastSeenMs (BIGINT): Timestamp of the last TCP event occurring within the 10 second aggregation interval. 
20. MessageType (VARCHAR): Event category (e.g., TCP_CONNECTION).
21. Hostname (VARCHAR): Hostname of the machine.
22. ActivityType (VARCHAR): Specific TCP activity (e.g., Connect, Disconnect).
23. EventTime (BIGINT): Time of the event 
24. ReceiveTime (BIGINT): Time when telemetry was received.
25. PID (INTEGER): Process ID.
26. ProcessName (VARCHAR): Name of the process.
27. AgentId (VARCHAR): Identifier for the telemetry agent.

### Wintap_ApiCall:  This table provides detailed information about API calls made by processes, which can be useful for analyzing process behavior, detecting anomalies, and investigating potential security issues.

13. MessageType (VARCHAR): The category of the event (e.g., API_CALL).

15. EventTime (BIGINT): The timestamp of when the event occurred, in Windows FileTime format.
16. ComputerName (VARCHAR): The name of the computer where the event occurred.
17. AgentId (VARCHAR): The ID of the agent that captured the telemetry data.
18. ActivityId (VARCHAR): A unique ETW identifier for the activity, useful for tracing related events.
19. CorrelationId (VARCHAR): An ETW identifier used to correlate related events across processes or threads.

### Wintap_Memory: This table provides detailed information about memory-related events, which can be used for analyzing memory usage, detecting anomalies, and understanding process behavior.
1. BaseAddress (VARCHAR): The base address of the memory region being described. Useful for identifying specific memory locations.
2. AllocationBaseAddress (VARCHAR): The base address where the memory allocation begins. Helps in understanding memory allocation patterns.
3. AllocationProtect (VARCHAR): Indicates the protection attributes applied to the memory allocation (e.g., read, write, execute). Useful for security analysis.
4. RegionSize (BIGINT): The size of the memory region in bytes. Useful for analyzing memory usage and allocation efficiency.
5. PageProtect (VARCHAR): Describes the protection attributes of individual memory pages within the region. Important for understanding memory access permissions.
6. PageType (VARCHAR): Indicates the type of memory page (e.g., private, mapped, image). Useful for categorizing memory usage.
7. MZHeaderPresent (BOOLEAN): Indicates whether an MZ header (used in executable files) is present in the memory region. Useful for detecting loaded executables.
8. PidHash (VARCHAR): A unique identifier for the process associated with the memory event. Can be used to join with other tables.
9. ProcessName (VARCHAR): The name of the process associated with the memory event. Useful for identifying the process context.
10. PID (INTEGER): The Process ID associated with the memory event. Another way to identify the process context.
11. MessageType (VARCHAR): The category of the event (e.g., MEMORY). Helps in filtering memory-related events.
12. ActivityType (VARCHAR): The specific action within the memory category (e.g., allocation, deallocation). Useful for understanding the type of memory activity.
13. EventTime (BIGINT): The timestamp of when the event occurred (in Windows FileTime format). Useful for temporal analysis.
14. ComputerName (VARCHAR): The name of the computer where the event occurred. Useful for identifying the system context.
15. AgentId (VARCHAR): The identifier of the Wintap agent that collected the data. Useful for tracing the source of telemetry.
16. ActivityId (VARCHAR): A unique identifier for the activity. Useful for correlating related events.
17. CorrelationId (VARCHAR): A unique identifier for correlating events across different categories. Useful for tracking related activities.
