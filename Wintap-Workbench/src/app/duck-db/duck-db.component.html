Getting Started with DuckDB
What is DuckDB?

DuckDB is an in-process database management system that allows you to analyze and query stored Wintap data.

Accessing Wintap Data

Wintap stores collected data in Parquet files at C:\ProgramData\Wintap\parquet\merged, organized by event type:

  • *raw_process*.parquet - Process creation events
  • *raw_tcp_process_conn_incr* - TCP network activity
  • *raw_udp_process_conn_incr* - UDP network activity
  • *raw_process_file* - File system operations
  • *raw_process_registry* - Registry operations
  • *raw_process_imageload* - Module/DLL load events

Wintap maintains a limit of 256MB of cached parquet data on disk until it begins pruning individual files on a first-in-first-out basis.

Example Queries
All processes 

    -- Load process events from parquet files
    CREATE OR REPLACE VIEW process_events AS
    SELECT * FROM read_parquet('C:\\ProgramData\\Wintap\\parquet\\merged\\*+raw_process*.parquet');;

    -- Query the view
    SELECT
    EventTime,
    ProcessName,
    PID,
    CommandLine
    FROM process_events
    ORDER BY EventTime DESC
    LIMIT 100;
All processes that connected to the internet 

    -- Load network events from parquet files
    CREATE OR REPLACE VIEW tcp_events AS
    SELECT * FROM read_parquet('C:\\ProgramData\\Wintap\\parquet\\merged\\*+raw_tcp_process_conn_incr*.parquet');;

    -- Query the view, converting IP addresses to dotted quad
    SELECT
        ProcessName,
        ActivityType,
        RemotePort,
        RemoteIp,
        SUM(MaxPacketSize) AS TotalBytes,
        MAX(EventTime) AS MostRecentEventTimeUTC,
        (TO_TIMESTAMP(MAX(EventTime)) AT TIME ZONE 'UTC') AT TIME ZONE 'America/Los_Angeles' AS MostRecentEventTimeLocal
    FROM (
        SELECT
            ProcessName,
            ActivityType,
            RemotePort,
            MaxPacketSize,
            EventTime,
            CONCAT(
                CAST((RemoteIpAddr >> 24) & 255 AS VARCHAR), '.',
                CAST((RemoteIpAddr >> 16) & 255 AS VARCHAR), '.',
                CAST((RemoteIpAddr >> 8) & 255 AS VARCHAR), '.',
                CAST(RemoteIpAddr & 255 AS VARCHAR)
            ) AS RemoteIp
        FROM tcp_events
    ) t
        WHERE RemoteIp NOT LIKE '127.0.0.1'
        AND RemoteIp NOT LIKE '192.168%'
        AND RemoteIp NOT LIKE '128.15.%'
        AND RemoteIp NOT LIKE '128.115.%'
        AND RemoteIp NOT LIKE '134.9.%'
        AND RemoteIp NOT LIKE '10.0.%'
    GROUP BY
        ProcessName,
        ActivityType,
        RemotePort,
        RemoteIp
    ORDER BY
    TotalBytes DESC;
