Getting Started with DuckDB
What is DuckDB?

DuckDB is an in-process database management system that allows you to analyze and query stored Wintap data.

Accessing Wintap Data

Wintap stores collected data in Parquet files at C:\ProgramData\Wintap\parquet, organized by event type:

  • \process_sensor\ - Process creation events
  • \tcpconnection_sensor\ - TCP network activity
  • \udppacket_sensor\ - TCP network activity
  • \file_sensor\ - File system operations
  • \registry_sensor\ - Registry operations
  • \imageload_sensor\ - Module/DLL load events
Example Query
Process Events Query 
-- Load process events from parquet files
CREATE OR REPLACE VIEW process_events AS
  SELECT * FROM read_parquet('C:\\ProgramData\\Wintap\\parquet\\process_sensor\\*.parquet');
  
-- Query the view
SELECT 
  EventTime, 
  ProcessName, 
  PID, 
  CommandLine
FROM process_events
ORDER BY EventTime DESC
LIMIT 100;
