Query Basics

Wintap queries use Esper EPL (Event Processing Language) syntax to filter and analyze events.

Simple Query Pattern

SELECT * FROM WintapMessage
WHERE MessageType = "PROCESS"
AND ActivityType = "Start"

Common Fields

  • MessageType: The type of event (PROCESS, FILE, etc.)
  • ActivityType: The action being performed (Start, Stop, Read, etc.)
  • PID: Process ID
  • ProcessName: Name of the process
  • EventTime: When the event occurred
